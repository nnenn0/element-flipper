# Element Flipper

## 概要

Element Flipper は、任意の Web ページ上の要素をワンクリックで左右反転（ミラー表示）できる Chrome 拡張機能です。  
デザイン確認などに便利です。
また、「自分と逆の利き手の人の動きや操作を真似したい」といった用途にも活用できます。
たとえば、右利きの人が左利きの人の操作動画を左右反転して観察することで、より直感的に動きを理解できます。

## 使い方

1. 拡張機能のアイコンをクリックし、「要素を反転（有効化）」を押します。
2. 反転したい要素にカーソルを合わせます。表示された枠と要素名を確認し、必要なら ↑ / ↓ キーで親・子要素を切り替えます。
3. クリックすると選択した要素が反転します。同じ要素を再度クリックすると元に戻ります。Esc キーで選択モードを解除できます。

## ファイル構成

- manifest.json: 拡張機能の定義ファイル
- popup.html: ポップアップ UI
- popup.js: ポップアップの動作スクリプト
- content.js: ページ上で要素を反転するコンテンツスクリプト
- icons: アイコン画像

## 権限

- `activeTab`: 拡張機能を開いたときに、現在のタブへの一時的なアクセスを許可
- `scripting`: 選択モードのスクリプトを現在のタブで実行
